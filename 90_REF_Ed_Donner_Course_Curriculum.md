## The Six Courses

| # | Course | What you can do after it |
|---|---|---|
| 1 | **AI Builder** | Create agents and voice agents with n8n and ElevenLabs, without writing code |
| 2 | **AI Coder** | Build software fast with coding agents like Claude Code |
| 3 | **AI Leader** | Deliver AI projects commercially, transform a business, start an AI business |
| 4 | **AI Engineer: Core Track** | Select, apply, and optimize LLMs for real commercial problems |
| 5 | **AI Engineer: Agentic Track** | The same, but with autonomous AI agents |
| 6 | **AI Engineer: Production Track** | Deploy LLMs and agents on the cloud at scale, with resiliency, observability, security |

**I'm in #4 — the Core Track.** That's the technical entry point and where the AI Engineer job title lives.

### What each of the AI Engineering trio covers
- **Core (4):** LLMs, APIs, open-source LLMs, RAG, fine-tuning
- **Agentic (5):** agent loops, OpenAI Agents SDK, MCP
- **Production (6):** deploy at scale to AWS, GCP, Azure

---

## Audience Split
- Courses **1–3**: technical or non-technical, wide audience
- Courses **4–5**: technical or aspiring-technical (curious, ready to get more technical)
- Course **6**: already technical, or has completed 1–5

---

## Order
- Any order works; they complement each other with little overlap.
- The natural progression is **1 → 6**, and that's what he'd pick himself.
- Otherwise, pick the topic that interests you.

**For an AI engineer role specifically, the critical path is 4 → 5 → 6.** Courses 1–3 are useful but not required for that goal.
